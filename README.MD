FlowchartCreationMiya v1.3.0

世界標準の作図ツール（VisioやDraw.io）に匹敵する機能を備えた、プロ仕様のフローチャート作成デスクトップアプリです。
PCにインストール等の複雑な環境構築は不要で、ダウンロードした実行ファイル(.exe)を開くだけですぐに使い始められます。

🚀 主な機能

[NEW] 線の終端スタイル切替: 線を「単なる線」か「矢印」か、書式ツールバーから選べるようになりました。

モダンUI＆テーマ切替: 美しいベクターアイコンと、目に優しいダークテーマ/ライトテーマをサポート。メニューの「表示」から切り替えられます。

自動階層レイアウト: ごちゃごちゃに置かれたノードも「★自動階層レイアウト」で一瞬で綺麗なツリー構造に自動整列されます。

直角配線（Orthogonal Routing）: Draw.ioのようにカクカクと曲がる美しい線を引くことができます。

仕様書の自動生成: フローチャートの繋がりを解析し、手順書としてExcelファイル (.xlsx) を自動生成します。

Draw.io 互換: 作成した図を Draw.io 形式で書き出し、ブラウザ版と相互に読み込み/編集が可能です。

CAD連携: ワンクリックでJw_cad形式としてクリップボードへコピー。

多彩な出力機能: 画像(PNG/JPEG)、SVG、DXF出力や、リアルタイムプレビュー付きの印刷機能に対応。

📥 ダウンロードと実行方法

GitHubの [Releases] ページ、または Actionの [Artifacts] から FlowchartCreationMiya-v1.3.0.exe をダウンロードします。

ダウンロードした .exe ファイルをダブルクリックして起動します。

⚠️ Windows Defender（SmartScreen）の青い警告画面が表示された場合
初回起動時、「Windows によって PC が保護されました」という画面が表示されることがあります。これはインターネットからダウンロードした新しいアプリに対する標準的な確認画面です。以下の手順で安全に起動できます：

メッセージ内の 「詳細情報」 をクリックします。

右下に現れる 「実行」 ボタンをクリックします。

💡 基本的な使い方

図形の配置: 上部のツールバーから「処理」「分岐」などの図形を選び、キャンバスをクリックして配置します。

線の接続: 「接続」ツールを選び、1つ目の図形をクリックした後、2つ目の図形をクリックして繋ぎます。

テキストの入力: 図形や線をダブルクリックすると、文字を入力できます。

スタイルの変更: 線を選択した状態で、ツールバーの「線幅」「線種」「ルート（直角など）」「終端（矢印）」を変更できます。

移動とコピー: 選択ツールで図形をドラッグして移動。Ctrl+Cでコピー、Ctrl+V（クリック）で貼り付けができます。
